# BladeRGB

**BladeRGB** — неофициальное приложение для управления поклавишной RGB-подсветкой клавиатуры **ARDOR GAMING BLADE** в Windows.

Текущая версия: **1.3.3 RU**. Интерфейс написан на **Qt Quick 6 / QML**, RGB/HID-движок — на Python.

> Проект не связан с ARDOR GAMING и не является официальным ПО производителя.

## Что исправлено в 1.1.1

- последнее состояние подсветки автоматически сохраняется после изменений и восстанавливается при следующем запуске;
- сохраняются не только именованные профили, но и текущие несохранённые изменения: эффект, палитра, яркость, параметры, покраска клавиш, Reactive RGB, Audio, слои и Animator;
- состояние дополнительно сохраняется при штатном выходе и завершении Windows-сессии;
- `settings.json` записывается через временный файл с атомарной заменой;
- общая яркость теперь регулирует основную подсветку, но не приглушает реакцию на нажатие клавиши;
- исправлен выбор цвета реакции: диалог больше не сбрасывает выбранный цвет обратно на белый;
- рядом с выбором цвета реакции отображается фактический HEX-цвет.

## Возможности

- поклавишная покраска: кисть, ластик и выделение;
- эффекты Aurora, Plasma, Wave, Rainbow, Gradient, Fire, Ocean, Matrix и другие;
- Reactive RGB: Ripple, Glow, Key Flash;
- Audio Reactive через системный Windows-аудиовыход;
- слои с масками, прозрачностью и режимами наложения;
- Screen Ambilight / Average / Edge;
- Animator с keyframes;
- сохранение и импорт/экспорт профилей `.brgb`;
- автоматическое переключение профиля по активному `.exe`;
- tray, автозапуск Windows и глобальные горячие клавиши;
- плавный crossfade между профилями.

## Поддерживаемое устройство

Протокол проверен на ARDOR GAMING BLADE со следующим HID-интерфейсом:

```text
VID        0416
PID        C345
Interface  MI_02
UsagePage  FF1B
Usage      0091
```

Передача RGB выполняется как виртуальный кадр 512 байт, разбитый на **8 HID-отчётов по 64 байта**. В проекте используется карта полноразмерной 104-клавишной раскладки, включая Numpad.

## Установка и запуск

Требуется **Windows 10/11** и **Python 3.11+**.

1. Полностью закройте официальную ARDOR Software, включая значок в системном трее.
2. Скачайте или клонируйте репозиторий.
3. Запустите `Start BladeRGB.bat`.

При первом запуске скрипт автоматически создаст `.venv` и установит зависимости из `requirements.txt`. Следующие запуски выполняются тем же `Start BladeRGB.bat` без повторной установки.

Если графическое окно не открылось, запустите `Start BladeRGB Console.bat` — консоль покажет traceback или QML-ошибку.

## Обновление существующей установки

Если BladeRGB уже установлен, замените файлы проекта на актуальные из `main`, но **не удаляйте `.venv`**. После этого запустите `Start BladeRGB.bat`.

## Сборка EXE

После успешного первого запуска выполните:

```text
Build EXE.bat
```

Результат появится в:

```text
dist\BladeRGB\BladeRGB.exe
```

## Горячие клавиши

| Комбинация | Действие |
|---|---|
| `Ctrl+Alt+F9` | включить / остановить RGB-движок |
| `Ctrl+Alt+F10` | Blackout |
| `Ctrl+Alt+F11` | предыдущий профиль |
| `Ctrl+Alt+F12` | следующий профиль |

## Структура

```text
blade/      HID-устройство, протокол и карта клавиш
engine/     эффекты, renderer, audio, reactive, layers, animator
app/        контроллер Qt и работа с настройками/профилями
qml/        интерфейс Qt Quick
config/     базовые настройки приложения
profiles/   локальные пользовательские профили
```

## Важно

- Не запускайте BladeRGB одновременно с официальной ARDOR Software: обе программы могут пытаться открыть один RGB HID-интерфейс.
- Проект не изменяет прошивку клавиатуры.
- Поддержка других клавиатур с VID/PID `0416:C345` не гарантируется: раскладка адресов светодиодов может отличаться.
